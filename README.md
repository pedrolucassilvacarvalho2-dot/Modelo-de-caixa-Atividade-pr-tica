# Black Goose Bakery - Atividade prática de modelo de caixa

Projeto estático em HTML e CSS para praticar os principais conceitos do modelo de caixa, com layout de uma padaria fictícia.

## Tecnologias

- HTML5
- CSS3
- Google Fonts

## Como executar

1. Clone ou baixe este repositório.
2. Abra o arquivo `bakery.html` em qualquer navegador moderno.

Não há dependências de build, instalação de pacotes ou servidor obrigatório.

## Conceitos de modelo de caixa praticados

- `box-sizing`
- `margin`
- `padding`
- `border`
- `border-radius`
- `box-shadow`
- fluxo com `float` e limpeza com `::after`
- responsividade com `@media`
